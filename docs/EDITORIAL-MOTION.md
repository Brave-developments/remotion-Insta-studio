# Optional Editorial Motion — pastel scene template

This repository now includes **one optional editorial motion template**, with three modes. It uses the creator's five selected pastels and never changes existing channel branding or recolours every Remotion render.

Source inspiration and shared design reference: [remotion-motion-kit Editorial Motion](https://github.com/Brave-developments/remotion-motion-kit/tree/main/templates/editorial-motion).
The implementation in this repository is an independent, simplified Remotion component—not a copy of the source creator videos.

## Theme palette (only five colours)

| Token | Value | Application |
| --- | --- | --- |
| Ivory | `#F2EFE7` | Editorial background |
| Paper white | `#FFFEFA` | White UI cards and caption surface |
| Mint | `#DEF4EA` | First card, subtle wash |
| Peach | `#FAE7D7` | Second card, subtle wash |
| Lilac | `#EDE6FE` | Third card, word emphasis and soft shadow |

Muted legibility greys are permitted solely for text (`#514D57`, `#817D87`), borders (`#CDC8D0`) and subtle shadows (`#AEA4B4`). No black cards, yellow highlights or unrelated colour accents in this template. Real, verified brand logos can retain their official colours when subsequently added as sourced evidence.

**Canonical constants:** `studio-kit/src/editorialPalette.ts`. Don't spread new ad hoc colour literals across channel source.

## Scene modes

- `illustrated-explainer` — serif headline, progressive pastel concept cards, illustrative notification, restrained spring entrance.
- `saas-ui` — pastel dashboard mockup, workflow status and subtle UI progress. **Simulation, not product evidence.**
- `product-comparison` — serif question, staggered pastel product cards, lettermarks as obvious placeholders until genuine logo assets are supplied.

Timing is based on the scene-local frame with `useCurrentFrame()`, `spring()`, `interpolate()`, and Remotion `Sequence`; the default render is 1080 × 1920 at 30fps. The visual is reusable and not tied to any particular channel or narration.

## Preview in Remotion Studio

The optional `EditorialMotionPreview` composition is registered in:
- top-level `src/Root.tsx`
- `projects/TOMORROW-EXE/src/Root.tsx`
- `projects/TOOLPROOF/src/Root.tsx`
- `projects/BUILDMODE-LAB/src/Root.tsx`

From the repository root, run:

```bash
npm install
npm run studio
# Choose EditorialMotionPreview (12 seconds / three modes)
npm run typecheck
npm run render:editorial
```

Use the relevant channel's `npm start` to see the same optional gallery.

## Activate per Reel scene — explicit JSON opt-in

For channels using `studio-kit/src/Engine.tsx`, add the following **only** to a selected scene in that channel's Reel JSON. For BUILDMode Lab, `reels-kit/src/player.tsx` supports the same field:

```json
{
  "id": "sample-scene",
  "editorial": {
    "template": "editorial-motion",
    "mode": "product-comparison",
    "layout": "upper",
    "headline": "Which tool fits your workflow?",
    "subheadline": "A comparison based on verified facts",
    "items": ["Tool A", "Tool B", "Tool C"]
  }
}
```

**This is an illustrative partial scene object.** Retain the existing mandatory `start`, `end`, `type`, `text` and `narration` fields when adding it to a real Reel. Remove the `editorial` property to switch back to the original channel visuals.

- `template` must equal `editorial-motion` exactly; otherwise the original renderer is used.
- `mode` is one of the three listed identifiers.
- `layout: "full"` creates a full editorial scene; `layout: "upper"` uses the upper 1160px and preserves the lower video region.
- To use an imported HeyGen presenter video below the graphics in an upper scene, add `"presenterAsset": "assets/path/to/presenter.mp4"` to the `editorial` object. The presenter video is **muted** so the parent Reel audio remains the only narration track. The path must correspond to real video under that project's public/assets; placeholder paths will not work.
- `emphasis` selects a phrase to highlight in lilac. Never highlight in yellow.
- `items` accepts up to three words or names as labeled illustrations, **not** fabricated evidence.
- Real captions remain on their existing timeline; during an editorial scene the captions use paper white and muted grey for contrast.
- No original project JSON has been automatically changed. Only specifically opted-in scenes take the pastel look.

## Production rules

Choose this only when the user explicitly requests/approves the editorial light-pastel motion style. Do **not** infer this template merely because a scene is generated by Remotion. Existing channel colours remain separate. Never make this the default for TOMORROW.EXE, TOOLPROOF, BUILDMode, FiveM promos, or scratch comps. Avoid invented product interfaces or unsupported claims.

Validate with typecheck and rendered MP4 before publication. A gallery preview demonstrates motion only; it does not verify footage timing or real product evidence.
