## Render edition narration

The plan compares LocalSend with a cloud route using exactly the same files. The inputs will be one hundred photos, a one-gigabyte video, and a five-gigabyte folder. Timing will cover sending and receiving. The cloud route must include upload and download. Received files will be checked for integrity. A separate run will interrupt Wi-Fi to examine recovery. Duration, file integrity, and recovery all need real capture. A moving diagram cannot establish transfer speed. Local networking is the starting condition. The final verdict will explain what changes when devices are apart.
