## Render edition narration

The test plan is Kando against the Start menu on ten everyday tasks. Both methods will launch the same apps, open the same folders, and reach the same commands. Setup will be counted separately. After practice, three timed rounds will alternate the method order. Every wrong selection will be logged. Speed only matters if the intended action opens. The result needs both median durations, error counts, and setup effort. No timings have been measured yet. The verdict will depend on the recorded workflow. Which of your daily actions would belong in this menu?
