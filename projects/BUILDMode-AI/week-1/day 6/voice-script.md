# BUILDMode-AI / day 6

**Codex Versus Codex Speed Test**

Compare two available coding configurations on one CSV-export task. Freeze the baseline before starting either run.

Headers, commas, quotes, embedded newlines, empty cells, and Unicode all matter. A file that looks right can still be broken.

Use clean copies and the same prompt. Stop each clock only after independent acceptance checks pass.

Inspect the exported data in another application. A quick answer does not win if it produces an unusable file.

Repeat paired runs when possible, alternate order, and report variation. The timing comparison remains open until measured.

This edition explains the test protocol. Which small task would make a useful speed and quality comparison?
