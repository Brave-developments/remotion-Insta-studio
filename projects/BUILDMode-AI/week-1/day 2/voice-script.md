# BUILDMode-AI / day 2

**Can an AI Finish a Browser Task?**

A browser agent should finish the task, not quietly hand it back. Here is a concrete way to check.

Research these five repositories. Collect stars, license, language, and latest default-branch update with source links.

The agent must browse the actual pages. Record blocked access, recovery, and every moment a person steps in.

Check the source behind every value. Last release and latest commit are different things; the table must be precise.

Judge correct fields, usable output, and interventions together. No filled-in score until the recorded run exists.

This edition shows the task and audit plan. What browser job would make you trust an agent?
