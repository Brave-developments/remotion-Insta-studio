Direct this as an observable challenge: Five deliberate bugs; identical repo/prompt; compare fixes, runtime and regressions. The viewer must see the starting problem, the exact constraint, one revealing action and the independently checked output. Let the real failure or correction create the turn. Save every first attempt. Completion claims alone never establish a result.

### Recording / build protocol

Prepare one local React fixture with five independently reproducible faults: invalid login handling, case-sensitive search, navigation overflow at 639px, dead Save action, and a seeded failing unit test. Freeze baseline commit, dependency versions and five acceptance checks. Select three accessible coding tools; record their exact model/configuration. Run one identical prompt on separate clean copies with a 20-minute cap and identical resource access. Log interventions, submission-to-verified-finish time, five fixes and regressions. No winner unless checks establish it; one run is exploratory, repeat before a broad claim.
