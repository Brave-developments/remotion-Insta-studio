# BUILDMode AI brief

**Positioning:** I build and test things with AI.

**Visual identity:** Premium developer software: real code, terminals, browser actions, app demos, test evidence and measured comparisons. Blue is a restrained brand accent.

**Pillars:** AI coding challenges; Real agent experiments; Small useful apps; Screenshot-to-interface builds; Open-source automation; Developer workflows.

**Cadence:** 2 Reels/day for 7 days; 14 planned.

Real experiments and test evidence are the substance. Do not render placeholders as factual outcomes. Verify access and functionality; show failures and limitations as well as successes.

- D02R1: Verify access, correct entries and interventions; imported feature claims require checking. Assets: Full browser run, table, failures/recovery.
- D02R2: Record the voice specification, transcript, build and functional checks. Assets: Waveform, transcript, agent run, final Kanban.
- D03R1: Confirm feature access; audit all four rules in a fresh task. Assets: Both sessions, rules, final code and tests.
- D03R2: Capture constraints, baseline and final; report actual improvements and failures. Assets: Ugly/final site, timer, coding recording.
- D04R1: Verify exact project/star count on recording day; audit all 24 extracted fields. Assets: Complete run, repo pages, CSV, interventions.
- D04R2: Fresh sessions and known seeded issues; record actual findings. Assets: Diff, skill folder, both reviews, findings.
- D05R1: Perform when commissioned; measure coordination, conflicts, tests and final app. Assets: Agent graph, real runs, merges, tests, app.
- D05R2: Use a test repo; validate behavior, regressions and actual outcome. Assets: Issue, diff, before/after, test results.
- D06R1: Confirm tier availability; use real timers and compare quality. Assets: Two runs, task, export, passing tests.
