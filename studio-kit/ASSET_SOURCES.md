# Existing asset sources

The parent workspace already contains pngs/tabler-icons-main and pngs/tabler-illustrations (including light illustration PNGs). Review images before choosing them. Use relevant assets instead of rebuilding a generic card. Copy selected files into the relevant channel's public/assets; do not duplicate the complete library into every channel.

The Tabler icon repository's LICENSE is MIT and includes a copyright notice for Paweł Kuna. Preserve that notice when reusing its files. The illustration directory's reuse rights need to be checked separately rather than assumed from the icon license.

Original vector icons and laptop artwork in studio-kit/src/Objects.tsx were authored during our local reel work. Shared script briefs separately list the real recordings/screenshots that still need to be created.
